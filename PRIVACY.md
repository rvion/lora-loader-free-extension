# Privacy policy

Civitai to LoRA Manager (unofficial) collects no personal data and sends
nothing to its author or to any third party.

What it reads and where it talks:

- **civitai.com**: it reads the model pages you open and calls Civitai's
  public API for those models, from the page itself, as your browser already does.
- **Your LoRA Manager**: it calls the address you set (by default
  `127.0.0.1:8188`) to check your library and to start downloads. That
  server is yours; nothing else receives these calls.

What it stores, in Chrome's extension storage on your device:

- the LoRA Manager address (synced by Chrome between your own browsers if
  you use Chrome sync), your folder rules, focus, marked models, last used
  folders, card positions and whether ad hiding is on.

No analytics, no tracking, no remote code, no data sale or transfer.
Removing the extension removes its stored data.
